# City index

GeoNames city coordinates, names, alternate names and population, taken from the cities15000 dataset bundled with geonamescache 3.0.2 (retrieved 2026-10-07). 34,006 records. The derived index keeps at most 18 alternate names per city; regional names are included for Canada and the United States. Country names come from the same dataset. It supports autocomplete without relying on an external service at runtime.

Source: https://github.com/yaph/geonamescache and https://www.geonames.org/export/
